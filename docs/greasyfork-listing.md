## 发布正文（复制这一段）

```markdown
网页视频硬字幕实时翻译：把画面上烧录的字幕（硬字幕）识别出来，实时翻译成中文并以悬浮字幕显示。

## 它解决什么问题

很多动画、短剧、生肉视频的字幕是**直接烧进画面**的，播放器读不到字幕轨，常规翻译插件也无能为力。
本脚本把字幕所在的这一小块画面临时截图，交给 OCR / 视觉大模型识别并翻译，再把译文盖回画面上。

## 核心功能

- 五种识别引擎，面板里切换：
  - **视觉大模型（默认）**：截图直接交给支持图片输入的模型，一步完成识别 + 翻译
  - **Umi-OCR**：识别交给本机运行的 Umi-OCR（离线、免费、浏览器端零下载），译文交给大模型，最省钱
  - **浏览器内置 AI**：用 Chrome 138+（或 Edge 148+）自带的模型在本机完成识别与翻译，不要 Key、完全免费；Chrome 上不联网、原文不出设备
  - **免费网页接口**：本机 Umi-OCR 识别 + 复用翻译网站自己的前端接口（腾讯 / 彩云 / 必应），不要 Key。⚠️ 属**非公开接口**，服务条款上通常不允许第三方调用、且随时可能失效，仅建议个人自用
  - **有道图片翻译**：一次调用完成识别 + 翻译
- 两种截图方式，跨域视频自动切换（优先直读 `<video>`；读不到像素时改用标签页捕获）
- 省钱跳过判定：画面没变、没有文字、字幕与上一句相同时都不调用 API
- 字幕样式可调：字号 / 描边 / 颜色 / 位置 / 背景透明度
- 按站点分别记忆框选区域；支持全屏播放与 SPA 换页
- 内置诊断模式，遇到问题可一键生成报告

## ⚠️ 数据与费用说明（请务必先读）

- 脚本**只上传你在页面上框选的那一小块区域**，不采集页面其它内容，也不含任何统计或埋点代码。
- 上传目标是**你自己填写的 API 地址**（DeepSeek、OpenAI 兼容接口、有道等），与脚本作者无关。
- 五种引擎里，**Umi-OCR、浏览器内置 AI、免费网页接口**这三种不需要付费；其余两种由你的 API 供应商**按量计费**，费用结算给该供应商，作者不收取任何费用。
- 「浏览器内置 AI」在 Chrome 上是端侧模型，**不发出任何网络请求**（首次需从 Chrome 下载一次模型）。
- 「免费网页接口」会把**识别出的字幕文本**发给你选定的那家翻译服务（腾讯 / 彩云 / 必应）—— 与其他引擎不同的是，它连的是非公开接口，随时可能失效，请自行评估是否使用。

## 关于 `*://*/*` 权限

「哪个网站有视频」无法预先枚举，因此脚本需要在任意页面检测是否存在 ≥200×120 的视频。
没有视频的页面只会出现一个可点击的小胶囊、不会注入任何其它内容；iframe 内没有视频则完全不挂载。

## 使用

1. 安装后打开任意有视频的页面，右下角会出现一个**小胶囊**（面板**默认收起**，不挡画面）
2. **点一下胶囊展开面板** —— 之后会记住这个选择，新页面直接展开；点标题栏的 × 可再收起
3. 选一种引擎：
   - 想省事：选平台预设、填入你自己的 API Key，点「测试 API」
   - 不想填 Key：引擎切到「浏览器内置 AI」，点「准备离线模型」；或切到「免费网页接口」（需先装好本机 Umi-OCR）
4. 点「框选字幕区」，在视频上拖出字幕所在的横条
5. 点「开始」

### v1.13.0

**更省钱了**

- **修掉一个持续漏钱的 bug**：当画面静止、但那一小块区域又认不出文字时（静止空镜、风景、标题卡都会命中），脚本会**每隔一个截图间隔就把同一张一模一样的图重新送去识别一次**，每次都计费、结果永远是空。现在同一张图只买一次。
- **切到别的标签页会自动暂停**：视频在后台标签页会继续播放，所以以前切走之后字幕翻译仍在全速调用付费接口，而没人看得到结果。现在切到后台即暂停、切回来自动继续（可在面板「节奏」区关掉）。
- **出错不再盲目重试**：撞上限流（429）现在会指数退避 1s→2s→4s…最多 60 秒，服务端限流恢复得更快；网络错误最多退避 15 秒。而 **API Key / 地址 / 模型名填错这类问题会直接停下并提示你去改**——以前会以约 2.7 秒的周期永远重试下去，既刷屏又白烧请求。

**修掉的问题**

- **停止后 45 秒内点「开始」没反应**：前一次请求还挂在网络上时，重新点开始会被静默忽略（状态栏显示「运行中…」但一轮都不跑）。现在可以立刻重开。
- **「浏览器内置 AI + 端侧读图」可能识别到错帧**：截图快照的时机反了，模型加载期间那张复用的画布可能已被下一帧覆盖。现在先取快照再等模型。
- **译文颜色有时显示成白色**：从「导入配置」带进 `#f00` 这类简写色值（或带透明度的 8 位色值）时会被静默当成白色。现在按 CSS 规则正确解析。
- **配置里的错误值更早被拦下**：API 地址 / Umi-OCR 地址填得不像网址、模型名为空、额外提示词过长、配置档案里混入脏数据，现在都在加载时就兜回默认值，而不是等到运行时报错。

**给开发者的（不影响使用）**

- 加了 GitHub Actions：产物一致性、语法检查与全部 523 项测试现在由 CI 自动执行。
- 新增 `_test/build.mjs`（27 项）给构建脚本补上此前完全缺失的覆盖，并让构建脚本对「模块依赖声明与实际使用不一致」做双向对账。
```

## 关于 Greasy Fork 会改动脚本的哪些部分

官方 [重写规则](https://greasyfork.org/en/help/rewriting) 说明，脚本在 Greasy Fork 上会被这样处理：

- `@updateURL` / `@downloadURL` 会被**添加或改写**为指向 Greasy Fork（`@installURL` 会被移除）；
- 缺失的 `@version` / `@namespace` 会被补上；
- CRLF 换行会被转换为 LF。

**实践含义**：GitHub 上的版本继续从 GitHub 更新，Greasy Fork 上的版本从 Greasy Fork 更新，两者互不干扰，因此**不需要**为了发布 Greasy Fork 而删掉脚本里的 `@downloadURL` / `@updateURL`。
